FRAUDWATCH / 02

The decision

  • Flag transactions for human review before execution.
  • Missed fraud and false alarms have different consequences.
  • A model score supports review; it does not prove fraud.
FRAUDWATCH / 03

Dataset and sampling

  • Read 6,362,620 rows; uniformly sampled 300,000.
  • Random priority sampling covers the whole file, independent of labels.
  • Source: PaySim on Kaggle. Financial values use dataset units.
FRAUDWATCH / 04

What the training data shows

  • Training fraud prevalence: 0.0732%. Accuracy alone can conceal missed fraud.
  • CASH_OUT is the most common transaction type in the training sample.
  • TRANSFER has the highest observed training fraud rate (0.4069%); this is an association.
FRAUDWATCH / 05

Features available at decision time

  • Inputs: type, amount, oldbalanceOrg, oldbalanceDest, step.
  • Derived: hour, amount/balance ratio, origin shortfall.
  • Exclude future balances, isFlaggedFraud, account IDs and the target.
FRAUDWATCH / 06

Validation protocol

  • Split complete time steps: earliest 60% train, next 20% validation, last 20% test.
  • Three expanding-window folds on training steps tune hyperparameters.
  • Fit imputation, encoding and scaling inside each training fold.
FRAUDWATCH / 07

Model comparison

  • Selected by training CV: Histogram gradient boosting.
  • Histogram gradient boosting: CV AP 0.9066
  • Random forest: CV AP 0.8762
  • Logistic regression: CV AP 0.5167
  • Baseline: constant training prevalence.
FRAUDWATCH / 08

Review threshold

  • Validation-selected cutoff: 0.00375.
  • Assumed costs: missed fraud 25, false alarm 1 units.
  • Minimize validation cost, then freeze model and threshold.
  • Costs are assumptions. Scores are not calibrated probabilities.
FRAUDWATCH / 09

Held-out test results

  • Average precision: 0.9708; ROC-AUC: 0.9970.
  • Precision: 0.9556; recall: 0.9556; F1: 0.9556.
  • Caught fraud: 86; missed fraud: 4; false alarms: 4.
  • Average precision summarizes the PR curve; it is not trapezoidal PR-AUC.

Errors and limitations
